# cyberScan — Next.js

Static HTML site rebuilt as a Next.js app.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Admin login (from `.env.local`)

- Username: `ADMIN_USERNAME`
- Password: `ADMIN_PASSWORD`

Default for local: `admin` / `Test123!`

## Data

JSON database: `data/db.json`  
Styles: `app/globals.css` (copied from the old `style.css`)
